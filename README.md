# Sunny Side Bakery

A short, cozy browser game. Grandma Rose threw out her back, so you run her little Main Street bakery for five days.

- Tap dough to put it in an oven, tap the oven when it glows golden, then tap a customer to hand over their order.
- Each day lasts about a minute. Earn stars, upgrade the shop, and uncover the story of Mr. Walter and the yellow roses.
- Works on desktop and phones. Progress is saved in the browser.

Play: open `index.html`, or enable GitHub Pages for this repository.

Character art: `img/` holds each character in three expressions (`-happy`, `-mid`, `-sad`) plus the ending scene.
